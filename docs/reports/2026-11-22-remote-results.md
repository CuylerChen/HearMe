# 2026-11-22 ai02-remote 实测

这些是实测，不是验收通过。P50 目标没有达到。模型、CUDA 和系统服务没有改。

| 项 | 结果 |
| --- | --- |
| TTS 第一段语义片段 | 1866 ms，采样率 24000，音频 3440 ms |
| ASR 0.5 秒流式，普通话样本 | 非空，墙钟 1249 ms，后端是 transformers 分块，因为官方 streaming_transcribe 要求 vLLM |
| LLM 第一段 | 609 ms |
| 端到端 20 轮第一块音频 P50 | 1284 ms，最小 1008，最大 1500，目标 1200，未达到 |
| 打断 | 第一块音频之后停止后续音频，接口返回小于 300 ms |
| 七种语言识别 | 六种引擎语言非空。普通话样本含「九点」或「开门」。西班牙语额外通过，没有替换任何一种 |
| 粤语 TTS | 模型不支持该语言，没有填写假说话人 |
| 法语音色 / 西班牙语音色 | 探测被真实说话人 aiden 接受，声音目录仍是 testing，未对用户开启 |
| 三模型常驻 | 7898 MiB，无 OOM |
| 停止后 GPU | 70 MiB |
| nginx、ollama、redis、docker | 仍是 active |
| 网关监听 | 只有 127.0.0.1:18200 |
| 倾诉探针 | logs、reports、tmp 中没有「隐私探针句子」 |
| 30 分钟单用户 | 未跑。P50 未过线，按任务顺序不把后续浸泡记为通过 |

SSH 映射 `18200` 后，本机可以创建会话、读取状态、打断和删除。状态响应不含转录文本。
