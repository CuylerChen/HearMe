# HearMe AI 正式 PRD

版本：v1.1  
状态：已确认，后续开发文档以本文件为准  
形态：Mobile-first Web + PWA，业务应用与语音主机分开实现

## 已确认决策

| 项目 | 正式规则 |
| --- | --- |
| 对话语言策略 | Auto Detect，自动识别 |
| 首发语言 | 英语、中文普通话、日语、韩语、西班牙语、法语 |
| 回复语言 | 默认跟随用户当前使用的语言 |
| 对话中切换语言 | 支持自动切换 |
| 混合语言 | 支持同一通话中混合使用多种语言 |
| 用户手动选择 | 可以设置首选对话语言，默认自动识别 |
| 界面语言 | 与 AI 对话语言独立设置 |
| 本地/云端 | 两种运行模式遵循相同语言策略 |
| 隐私 | 不保存录音、转录文本、对话内容或语言识别历史 |

用户不需要先选择语言，也不需要了解 ASR、TTS 或模型配置。

说中文，AI 用中文回应。说英语，AI 用英语回应。先说中文后改说英语，AI 自动跟随。中英混合时，AI 理解上下文并自然回应。

核心原则：Speak naturally. HearMe understands.

HearMe AI 是日常倾诉和情绪陪伴产品。不宣传、不设计为心理治疗、诊断或危机干预服务。

所有倾听风格共用同一份基础 System Prompt：先听、不评判、自然交流、建议由用户决定、不保留上一通内容。明确的自伤、自杀或伤害他人风险不走这套闲聊提示，改为平静地请对方联系当地紧急服务和信任的人。人在美国且有即时危险时，可以拨打或短信 988；生命危险联系 911。不承诺保密到足以阻止对方寻求现实帮助，也不让对方把 HearMe 当成唯一支持。

| 原则 | 正式规则 |
| --- | --- |
| Listen First | 先听，不急于回答 |
| No Judgment | 不评判用户 |
| Natural Conversation | 自然交流，不像机器人 |
| User Control | 用户决定是否需要建议 |
| Privacy First | 不依赖长期记忆，不保留对话内容 |

AI 不因语言变化改变基本人格：温柔、耐心、不评判、优先倾听。建议只在用户要的时候出现。语言切换不重新开始这一通对话。上一通的内容不带入下一通。

## 首发语言

这六种语言是产品首发验收范围。它们不代表每个本地模型和每个云端模型天然具备同等质量。每种语言单独完成识别、理解和语音合成测试后，才能对用户标记为可用。

| 代码 | 语言 |
| --- | --- |
| en | English |
| zh-CN | 简体中文，普通话 |
| ja | 日本語 |
| ko | 한국어 |
| es | Español |
| fr | Français |

粤语不是这六种首发语言之一。本地模型能识别粤语，这份能力用来避免把粤语音频当成普通话通过，不把粤语算进首发清单，也不用它替换西班牙语。

## 自动识别

| 场景 | 系统行为 |
| --- | --- |
| 首次开始通话 | 自动识别用户语言 |
| 用户持续使用一种语言 | 保持该语言回复 |
| 用户切换语言 | 确认新语言后，下一轮回复切换 |
| 中英混合表达 | 按主要表达语言和上下文选择回复语言 |
| 短暂说出外语单词 | 不切换 |
| 环境噪声导致识别不确定 | 不频繁改变语言 |
| 识别失败 | 请求用户重复，不猜测语言 |
| 用户指定首选语言 | 只在自动识别不确定时作为优先参考 |

不能因为用户说了一个外语单词，就让 AI 从当前语言突然切走。

初始工程参数，可按真实音频调整，不是不可改的产品常量：

| 参数 | 初始目标 |
| --- | --- |
| 最低语言置信度 | 0.80 |
| 连续确认片段 | 2 个，用于切换，不用于挡住第一次识别 |
| 短语音过滤 | 少于约 1.5 秒不单独触发切换 |
| 语言切换响应 | 下一轮 AI 回复生效 |
| 不确定时 | 保持当前语言 |

已安装的 Qwen3-ASR 不返回校准后的置信度。实现用连续片段和时长做切换稳定，不把模型没给出的分数写成模型输出。

## 界面语言与对话语言

两个设置互相独立。

| 设置 | 默认行为 |
| --- | --- |
| Interface Language | 首次按浏览器语言选择，用户可以修改 |
| Conversation Language | Auto Detect |

界面文案、日期、数字和货币按界面语言处理。AI 说话的语言只由对话语言策略决定。

业务系统保存用户主动设置的界面语言和首选对话语言。语音主机不保存这些偏好，每次会话由业务系统传入。

## 声音

四种 HearMe 声音继续保留：Gentle、Calm、Warm、Thoughtful。

每种声音按语言维护可用状态。某个声音在某种语言没有通过试听、发音、语速和情绪评估时，保持关闭。不可用胜过用错误语言的声音回复。

本地 0.6B CustomVoice 不支持 instruct。不能靠指令文本假装做出未经验证的音色。

## 隐私

| 数据 | 是否允许保存 |
| --- | --- |
| 用户语音 | 不允许 |
| ASR 转录文本 | 不允许 |
| AI 回复 | 不允许 |
| 对话摘要 | 不允许 |
| AI 情绪推断 | 不允许 |
| 每次会话的语言识别历史 | 不允许 |
| 用户主动设置的界面语言 | 允许，存在业务系统 |
| 用户主动设置的首选对话语言 | 允许，存在业务系统 |
| 会话使用时长 | 允许 |
| Provider 类型 | 允许 |

额外要求：

- 本地 ASR 不把转录写入日志。
- LLM 调试模式不打印用户对话。
- TTS 临时音频在会话结束时清理。
- 切到云端必须获得用户明确授权。
- 不为语言识别绕过本地优先。
- 语言识别失败时，不把完整录音自动上传云端补救。
- 新会话不继承上一通话的内容。

## 体验目标

这些是目标，不是已经达到的成绩。

| 指标 | 目标 |
| --- | --- |
| 用户停顿至 AI 首次发声 | P50 ≤ 1.2 秒 |
| AI 打断响应 | ≤ 300 ms |
| 语言切换 | 下一轮回复使用新语言 |
| 连续通话 | 30 分钟无异常 |
| 对话内容持久化 | 0 |
| 未授权云端音频上传 | 0 |
| 新会话历史继承 | 0 |

某种语言的 ASR 或 TTS 未通过测试，就不能因为宣传需要标记为完整支持。本地和云端分别维护能力状态。

## 范围

本仓库实现语音服务和正式文档。官网、App、账号、订阅和界面国际化由业务系统单独实现。

语音主机只提供与第三方语音 API 同类的功能接口：创建会话、查询状态、提交音频、接收回复音频、打断、结束会话。它不实现倾诉页面，不保存用户档案。
